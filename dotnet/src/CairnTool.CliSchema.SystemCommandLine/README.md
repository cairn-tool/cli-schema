# CairnTool.CliSchema.SystemCommandLine

System.CommandLine 2.x emitter for the portable CLI-description schema. Depends on `CairnTool.CliSchema` (the model) and System.CommandLine.

```csharp
using CairnTool.CliSchema;
using CairnTool.CliSchema.SystemCommandLine;

rootCommand.AddDescribeCommand(registry);
```
